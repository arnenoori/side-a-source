# Side A 0.4.0

- Setup checks Python and your agent CLI, and shows what needs installing or updating. Return from the installer and Side A checks again.
- Optional anonymous app statistics help improve account setup and handoffs. Off by default; change this any time in Settings. No account identities, code, or conversations are collected.
- Signed automatic updates through Sparkle. Checks and downloads happen in the background; an active coding session can finish before the app relaunches.

macOS 14 or later. Apple Silicon and Intel. Free public preview.

Existing 0.3.1 users need to download this version once to enable the updater. Claude and Codex sessions must be started from Side A. Codex and Auto flip remain experimental; real multiple-account handoffs are still undergoing acceptance testing.
