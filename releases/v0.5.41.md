# Side A 0.5.41

- Pool mode keeps prompt caches for an hour, as Claude Code does with your own login, so pauses no longer cost you limits.
- Pool mode is safer: only `claude` gets its key, your own API settings are left alone, and it only ever talks to Anthropic's API.
- Signing out of an account keeps it signed out.
- Automated runs (`claude -p`, scripts) finish quietly in the Done list instead of popping up in the notch.

macOS 14 or later. Apple Silicon and Intel. Free.
