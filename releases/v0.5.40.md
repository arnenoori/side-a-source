# Side A 0.5.40

- Accounts no longer get stuck after a `/login` in a session: Side A points each account at the login it really holds, lets every account sign in again, and puts back a login that was written over.
- Pool mode (Autopilot, off by default): Claude Code in Terminal goes through Side A, which keeps each conversation on one account and moves it the moment that account is full, with no wait for sessions to pause.
- Search in Settings: press ⌘F and type to find any setting.

macOS 14 or later. Apple Silicon and Intel. Free.
