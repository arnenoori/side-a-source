# Side A 0.5.24

- Dynamic Island: approve Claude Code and Codex permission requests from the notch, with the command or diff in view. ⌃⌥Y allows, ⌃⌥N denies, ⌃⌥A always allows; the terminal prompt stays open too.
- Destructive commands like `rm -rf` or a force push are marked and need a click.
- Answer Claude's questions and review its plans from the island.
- Know the moment a session is done, and give it its next task with Reply (⌃⌥R): it wakes and starts on it. Go (⌃⌥G) opens its own terminal tab, Warp included.
- Sessions shows what each running session is doing, flags ones that are stuck, looping, failing or carrying a huge context, and lets you send a note or stop one without leaving Side A.
- Fully accessible: VoiceOver announcements, keyboard focus with ⌃⌥I, Reduce Motion, and a pill on displays without a notch.
- Usage shows what your tokens would have cost at API prices, and can notify you when an account passes a share of its week.
- An incident on status.claude.com that reaches Claude Code shows in the menu, so outages aren't mistaken for account trouble.
- Autopilot waits for a pause in the work before an optional trade, so running sessions keep their prompt cache.
- Autopilot plans each running login by the models its own sessions use, and keeps Fable sessions going by trading with a login that only runs other models.

macOS 14 or later. Apple Silicon and Intel. Free.
