Side A turns your coding accounts into tracks on an interactive 3D Mac player.

- Switch between isolated Claude Code and Codex accounts.
- Open the lid to connect accounts with the agent's official sign-in.
- Use the physical player controls or the menu bar companion.
- Optionally attempt a safe conversation handoff when an account reaches a supported limit.
- Universal app for Apple Silicon and Intel, signed by Arne Noori and notarized by Apple.

Download the DMG, open it, and drag **Side A.app** into Applications. Updates are
manual downloads; replacing the app preserves its account metadata and history.
The ZIP is an alternative. `SHA256SUMS.txt` contains both downloads' SHA-256 checksums.

**Requirements:** macOS 14+, Python 3.9+, and separately installed
[Claude Code](https://code.claude.com/docs/en/setup) or
[Codex CLI](https://developers.openai.com/codex/cli). You need your own agent account.

**Public preview:** Codex integration is experimental. Tested CLI contracts are
Claude Code 2.1.263 and Codex 0.148.0. Live multi-account OAuth and real-limit
handoffs remain acceptance checks; automated tests use fixture agents. Side A
manages sessions it launches, resumes at the agent's prompt, and does not replay
your request automatically. It does not switch Claude Desktop or Codex desktop accounts.

This is an Apple-notarized direct download, not a Mac App Store release.
