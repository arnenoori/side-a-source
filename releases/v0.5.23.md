# Side A 0.5.23

- Fixes every account showing Couldn't connect, and Autopilot stopping, while your Mac is busy. A slow check no longer makes Side A lose track of Python, Claude Code or Codex.
- A Homebrew Python upgrade no longer takes Side A offline: it finds Python by its versioned name when `python3` goes missing.
- If Python ever goes missing, Side A checks again each minute and picks up as soon as it's back, without opening Settings.

macOS 14 or later. Apple Silicon and Intel. Free.
