# sidead 0.2.0

- Allow and Deny from your iPhone: run `sidead hooks on` and Claude Code's permission requests on this computer go to Side A Remote, with Face ID for the risky ones. "Always" rules and "Allow and accept edits" work too. `sidead hooks off` takes the hook out again, and with the daemon stopped Claude Code asks in the terminal as usual.
- Upgrade: run the install line again, `curl -fsSL https://getsidea.com/install.sh | sh`.
- Not yet: questions and plans, Codex requests, Autopilot, photos, the terminal view.

x86-64 and arm64, glibc 2.39 or newer (Ubuntu 24.04, Debian 13, Fedora 40), tmux 3.4 or newer, Python 3.9 or newer. Packages: a tarball and a .deb for each architecture, with SHA-256 sums.
