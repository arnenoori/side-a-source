# Studio reflections

The committed `src/studio.env` is the gzip-compressed RGBA half-float CubeUV texture generated by Three.js RoomEnvironment + PMREMGenerator at size 64, sigma 0.04, near 0.1, far 100. The dimensions are in `src/environment.json`. It preserves the studio reflections while avoiding cubemap rendering and repeated blur shader compilation on every visit.

To regenerate after changing the lighting or Three.js version:

1. From `site/`, run `node tools/bake-environment.mjs`.
2. Open the printed local URL in a WebGL-capable browser.
3. Press **Bake studio reflections**. The local tool writes the two source assets.
4. Rebuild the site and compare the player before committing the assets.

The tool binds to loopback only, checks the request origin and exact payload shape, and is not included in the production build.
