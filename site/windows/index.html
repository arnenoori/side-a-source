Side A for Windows Preview

Answer your Windows PC’s Claude Code and Codex sessions from your iPhone.

Windows 11, or Windows 10 22H2, with WSL 2. Runs inside WSL 2, and only sees Claude Code and Codex installed there. Not yet tried on a Windows PC.

Coming soon

Install

  1. In PowerShell, run wsl --install -d Ubuntu-24.04 and restart.
  2. In Ubuntu, turn on systemd once with printf '[boot]\nsystemd=true\n' | sudo tee /etc/wsl.conf, then run wsl --shutdown in PowerShell and open Ubuntu again.
  3. In Ubuntu, install Side A:
curl -fsSL https://getsidea.com/install.sh | sh

Then run sidead pair and scan the code in Side A Remote. Check that both show the same six digits.

What works

  • Claude Code and Codex sessions running in WSL, their transcripts and replies.
  • Starting sessions from the phone, kept in tmux.
  • Each Claude account’s 5-hour and weekly limits.
  • Reaching the PC away from home, and a push when a session finishes.

Not yet

  • Claude Code and Codex installed on Windows itself, outside WSL.
  • A Windows app or tray icon. The iPhone is the only interface.
  • Everything Side A for Linux doesn’t do yet.

Windows details

Remove

In Ubuntu, run ~/.local/share/side-a/uninstall.sh. sidead adds nothing to your shell, ~/.claude or ~/.codex.
