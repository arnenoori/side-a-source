Side A for Linux

Answer your Linux computer’s Claude Code and Codex sessions from your iPhone.

x86-64 or arm64. glibc 2.39 or newer: Ubuntu 24.04, Debian 13, Fedora 40. tmux 3.4 or newer, Python 3.9 or newer.

Coming soon

Install

curl -fsSL https://getsidea.com/install.sh | sh

Then run sidead pair and scan the code in Side A Remote. Check that both show the same six digits.

Packages

  • x86-64: .tar.gz · .deb
  • arm64: .tar.gz · .deb
  • SHA-256 sums

What works

  • Your running Claude Code and Codex sessions, their transcripts and replies.
  • Starting sessions from the phone, kept in tmux.
  • Each Claude account’s 5-hour and weekly limits.
  • Reaching the computer away from home, and a push when a session finishes.

Not yet

  • Allow and Deny for permission requests, questions and plans.
  • Autopilot and moving logins between sessions.
  • Photos, the terminal view, worktrees and pull requests.
  • A tray icon or settings window. The iPhone is the only interface.

Side A for Windows · Linux details

Remove

Run ~/.local/share/side-a/uninstall.sh, or sudo apt remove side-a-daemon for the .deb. sidead adds nothing to your shell, ~/.claude or ~/.codex.
