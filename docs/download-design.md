# Download experience

The existing Blender player is the primary visual reference. Preserve its satin
silver body, graphite controls, green LCD, and orange PLAY key. Refero's bundled
craft and motion references supply keyboard focus, reduced-motion behavior, stable
layout, and short, interruptible transitions. This is a direct extension of the
existing product, not a new brand direction.

| Decision | Reference | Purpose |
| --- | --- | --- |
| Actual exported Blender geometry in Three.js | `design/SideA.blend` and the native app | Let visitors try the object they are downloading |
| Near-white canvas, graphite type, orange used sparingly | Existing player materials | Keep the object central and visually consistent |
| One download action; setup details on demand | User's one-page and minimal-copy brief | Make installation the obvious next step |
| Native app and Applications icons in a custom DMG | macOS installation convention | Familiar drag-and-drop behavior with a product-specific printed insert |
| Visible keyboard focus and reduced motion | Refero craft/motion references | Keep the playful object accessible |

The landing page uses the real model as its main content. No feature grid, pricing
section, testimonials, or unnecessary onboarding prose. The download button becomes
available only when GitHub has a published release with the signed DMG and checksum.
The setup panel explains the separately installed CLI/Python requirements and the
three steps: install, connect an account, press PLAY.
